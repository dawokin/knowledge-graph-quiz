# Инструкция для тех, кто раньше этим не занимался

Это пошаговое руководство рассчитано на человека, который никогда не
запускал программы через терминал и не пользовался API нейросетей. Если
что-то из README.md было непонятно — начни отсюда.

Всего два больших шага: **(1)** один раз завести бесплатный ключ у DeepSeek,
**(2)** один раз установить и запустить само приложение на компьютере. После
этого пользоваться им — просто открывать страницу в браузере.

---

## Шаг 1. Получить ключ DeepSeek API

Ключ — это как пароль, по которому DeepSeek понимает, что запросы твои, и
считает их именно на твой счёт.

1. Открой в браузере [platform.deepseek.com](https://platform.deepseek.com/)
   и зарегистрируйся (почта или аккаунт Google/GitHub — что предложат).
2. После входа найди в меню слева раздел **API Keys** (или зайди сразу по
   ссылке [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys)).
3. Нажми **Create new API key**, дай ключу любое название (например
   "knowledge-graph-quiz") и подтверди.
4. Ключ покажется **один раз** — сразу скопируй его целиком (обычно строка
   вида `sk-...`) и сохрани куда-нибудь (в заметки, менеджер паролей). Если
   закрыть окно, не скопировав — придётся создавать новый ключ.

**Про бесплатное использование:** у новых аккаунтов обычно есть какой-то
стартовый бесплатный лимит токенов на пробу — но точные условия и цифры
меняются, и мы сознательно не указываем здесь конкретные числа, потому что
не смогли свериться с официальной страницей на момент написания этой
инструкции (см. README, раздел про CORS — из окружения, где собиралось
приложение, сам домен DeepSeek был недоступен). Актуальные условия всегда
смотри в своём личном кабинете на platform.deepseek.com — там же, где ключ,
обычно есть баланс/лимиты. Регистрация и сам ключ бесплатны в любом случае;
платить (если понадобится) нужно только после исчерпания стартового лимита,
и то не автоматически, а только если сам пополнишь баланс.

Держи ключ в секрете — это как пароль от банковской карты для DeepSeek: тот,
у кого есть ключ, может тратить деньги с твоего баланса.

## Шаг 2. Установить программы, без которых ничего не запустится

Приложению для запуска на твоём компьютере нужен **Node.js** — это среда для
выполнения JavaScript-кода вне браузера, на ней работает сборка проекта.

1. Зайди на [nodejs.org](https://nodejs.org/).
2. Скачай версию **LTS** (не "Current") — там будет крупная зелёная кнопка
   с подписью "LTS".
3. Запусти скачанный установщик и везде жми "Next"/"Далее" со стандартными
   настройками — ничего специально настраивать не нужно.
4. Проверь, что всё встало: открой терминал (см. ниже, как) и введи:
   ```bash
   node -v
   ```
   Если увидел что-то вроде `v20.11.0` — всё получилось.

**Что такое терминал и как его открыть:**

- **Windows:** нажми Win, набери "PowerShell" или "Терминал", открой.
- **macOS:** нажми Cmd+Пробел, набери "Terminal", открой.
- **Linux:** обычно Ctrl+Alt+T, либо ищи "Terminal"/"Консоль" в приложениях.

Это чёрное (или белое) окошко, куда можно печатать команды и жать Enter —
дальше всё общение с приложением будет именно через него.

---

## Шаг 3. Скачать код приложения

Если у тебя уже есть эта папка (например, ты её куда-то скачал/склонировал) —
пропусти этот шаг.

Самый простой способ без установки Git: на странице репозитория на GitHub
нажать зелёную кнопку **Code → Download ZIP**, распаковать архив в удобное
место (например, на Рабочий стол).

Если Git уже установлен, вместо ZIP можно выполнить в терминале (замени
ссылку на настоящий адрес репозитория):

```bash
git clone <ссылка-на-репозиторий>
```

## Шаг 4. Запустить приложение

1. В терминале перейди в папку с проектом. Если распаковал ZIP на Рабочий
   стол в папку `knowledge-graph-quiz`, команда будет такой (Windows):
   ```bash
   cd Desktop\knowledge-graph-quiz
   ```
   На macOS/Linux:
   ```bash
   cd ~/Desktop/knowledge-graph-quiz
   ```
   Подсказка: можно набрать `cd ` (с пробелом в конце), а затем перетащить
   мышкой саму папку из проводника/Finder прямо в окно терминала — путь
   подставится сам.

2. Установи зависимости проекта (нужно один раз, займёт минуту-две, нужен
   интернет):
   ```bash
   npm run install:all
   ```
   Это скачает все библиотеки, от которых зависит приложение (React,
   vis-network и т.д.) — они не входят в код, а подгружаются отдельно.

   **На Windows в PowerShell** эта команда может выдать ошибку вида
   *"выполнение сценариев отключено в этой системе"* (`UnauthorizedAccess`,
   `PSSecurityException`) — это не ошибка проекта, а стандартная защита
   Windows, которая по умолчанию блокирует запуск `.ps1`-скриптов (npm на
   Windows именно так и устроен). Лечится один раз:
   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
   ```
   Подтверди нажатием `Y`, затем повтори `npm run install:all`. Если менять
   системные настройки не хочется — открой вместо PowerShell обычную
   **Командную строку** (Win → набрать `cmd`), она этой командой не
   ограничена, и продолжай в ней.

3. Запусти приложение:
   ```bash
   npm run dev
   ```
   В терминале появится что-то вроде:
   ```
   ➜  Local:   http://localhost:5173/
   ```
   Это означает, что приложение работает. **Терминал с этой командой нужно
   оставить открытым** — если его закрыть, приложение остановится.

4. Открой в браузере адрес **http://localhost:5173/** (скопируй его из
   терминала или из этой инструкции).

Чтобы в следующий раз снова открыть приложение — просто повтори шаг 4
(команда `npm run install:all` из шага 2 нужна только один раз, при первом
запуске, или после обновления кода).

---

## Шаг 5. Настроить ключ внутри приложения

1. При первом открытии страница сама покажет экран **«Настройки»**.
2. В поле **DeepSeek API ключ** вставь ключ, скопированный в Шаге 1.
3. Поле **Base URL** и **Модель** — не трогай, оставь пустыми/по умолчанию.
4. Нажми **Сохранить**.

Ключ сохранится в этом браузере (в `localStorage`) — при следующих запусках
вводить его заново не придётся, пока не нажмёшь «Удалить ключ» или не
почистишь данные сайта в браузере.

## Шаг 6. Пользоваться приложением

1. **Ввод материала.** На главном экране — большое текстовое поле. Вставь
   туда ссылки и заметки, **каждую с новой строки**. Например:
   ```
   https://ru.wikipedia.org/wiki/Python - язык программирования
   Заметка: сегодня узнал про списки и словари в Python
   https://ru.wikipedia.org/wiki/Git - система контроля версий
   ```
   Не знаешь, что вставить для пробы — нажми кнопку **«Вставить пример»**,
   она подставит готовый тестовый набор.
2. Нажми **«Построить граф»** и подожди несколько секунд — приложение
   отправит текст в DeepSeek, тот разложит всё по категориям и найдёт связи.
3. Откроется **граф**: кружки — это твои ссылки/заметки, цвет — категория,
   стрелки между ними — смысловые связи. Можно:
   - таскать узлы мышкой, крутить колесо мыши для зума;
   - кликнуть по узлу — слева появится карточка с деталями;
   - в левой панели — список категорий и сколько элементов в каждой.
4. Кнопка **⚙ (шестерёнка)** в правом верхнем углу — всегда открывает
   настройки (сменить/удалить ключ).
5. Кнопка **«Начать квиз»** снизу слева — запускает проверку знаний:
   - ИИ задаёт вопросы по твоему же материалу (с вариантами ответа или
     открытые, куда пишешь ответ текстом);
   - после каждого ответа сразу видно, верно или нет, и объяснение;
   - в конце — итоговый счёт.
6. **«← новый ввод»** наверху левой панели — стирает текущий граф и
   возвращает к пустому полю ввода, если хочешь начать с новых материалов.

Обновление страницы (F5) ничего не стирает — граф сохраняется в браузере
автоматически.

## Если что-то не работает

- **"command not found: npm"** — Node.js не установился или терминал не
  видит его; переустанови Node.js (Шаг 2) и открой терминал заново.
- **"выполнение сценариев отключено в этой системе" / `PSSecurityException`
  в PowerShell на Windows** — см. пояснение и команду-решение в Шаге 4,
  пункт 2.
- **Ошибка в приложении после «Построить граф»** — почти всегда текст
  ошибки на экране объясняет причину (неверный ключ, лимит запросов,
  проблема с сетью). Самые частые:
  - *«DeepSeek отклонил API-ключ (401)»* — ключ скопирован не полностью
    или уже удалён в личном кабинете DeepSeek; создай новый (Шаг 1).
  - *«Превышен лимит запросов (429)»* — закончился баланс/бесплатный лимит;
    проверь баланс на platform.deepseek.com.
  - *«Не удалось получить ответ от DeepSeek API»* — проблема с сетью или
    блокировкой запроса браузером; см. README, раздел «CORS и когда
    всё-таки нужен прокси».
- **Закрыл терминал, и сайт перестал открываться** — это нормально,
  повтори Шаг 4 (`npm run dev` в папке проекта).
